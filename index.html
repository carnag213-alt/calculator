Калькулятор прогноза дотекания выручки

v10.1 · 2026-08-02
Инструкция

Работает ТОЛЬКО с данными по выручке за весь квартал

  1. Для прогноза дотекания выберите нужный квартал в отчёте
  2. Перейдите во вкладку Когорты
  3. Возьмите ТОЛЬКО ту выручку, которая попала в этот квартал
  4. Суммируйте выручку по месяцам:
    1 месяц — суммируем апрель + май + июнь
    2 месяц — суммируем май + июнь
    3 месяц — берём только май
    Данная логика работает на все кварталы (только там будут свои месяцы)
  5. Внесите полученные суммы в поля «Выручка» и «Расходы» для Бренда и/или Небренда
